# SignConnect Full-Stack Project

Welcome to the **SignConnect** codebase. This repository contains the assistive Indian Sign Language (ISL) communication platform created with Google Stitch designs and now engineered into a professional frontend architecture.

## Directory Structure

- **`frontend/`**: The modern, modular frontend application structured with dedicated folders for every page.
  - Run with `cd frontend && python server.py` or double-click `frontend/run-dev.bat`.
  - Open `http://localhost:3000/` to explore the interactive Architecture Hub or open `http://localhost:3000/pages/home/index.html`.
- **`Stich_sign connect/`**: The original Google Stitch design export files, preserved for reference and visual design comparisons.

For detailed documentation, refer to [`frontend/README.md`](./frontend/README.md).
